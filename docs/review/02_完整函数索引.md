方法：对 Makefile 中的 16 个 C++ 源文件做 Clang 语法树静态提取，并阅读实现补充说明。所有翻译单元解析成功；这不代表已在 Fedora 上运行验证。直接调用表显示函数体中可能发生的调用，不代表它们每次都执行，也不表示执行顺序。

普通调用以签名区分重载。构造、隐式析构、容器内部复制和 new/delete 的寿命关系不作为普通调用边逐一展开；参考架构笔记和下方生命周期说明。main→handleSignal 是信号注册关系，已人工补入。库调用显示 AST 中的名称，可能省略标准库所属类型；详见知识点表。

## 0. 生命周期关系（不等于普通调用）

- main 的局部对象：ConfigParser、ConfigValidator、Server；离开作用域自动析构。
- Server::acceptClient 构造 Client，再按值放入 map；Client 内含 RequestState，RequestState 内含 HttpRequest。
- Server::processRequest 构造 RequestHandler、HttpResponse；parseClientRequest 构造 RequestParser。
- Server::startCgi 使用 new CgiHandler；removeCgi 和 Server 析构使用 delete。
- ConfigParser 构造 Tokenizer、TokenStream、ServerConfig、LocationConfig、ListenConfig；容器按值保存配置。
- RequestHandler 各处理函数构造 HttpResponse；parseMultipart 构造 MultipartPart。
- 配置、请求、响应、Client 的拷贝/赋值可能通过容器或返回值发生，复制消除可能减少实际调用次数。
