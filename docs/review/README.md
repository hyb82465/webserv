# Webserv 项目复习手册

推荐双击 index.html，用浏览器打开。无需启动 Docker、webserv 或网络服务。

1. 先看三张结构图，再阅读《01_架构与运行流程》。这里串起启动、请求解析、文件处理、CGI、发送、超时和资源清理。
2. 查《02_完整函数索引》。251 个显式 C++ 定义逐一说明作用、调用者、被调用函数和源码位置；另列 11 个仅声明接口，以及 36 个 Python 函数和 6 个命名 lambda。
3. 逐项阅读《03_分类知识点》。283 个编号条目覆盖 C++、标准库、配置、网络、poll、HTTP、文件安全、CGI、内存、Session、Makefile、测试与静态页面。
4. 精确查成员和访问权限时，打开《04_全部类型声明》。这是当前 19 个头文件的原文索引。

网页功能：左侧章节导航；顶部关键字筛选；函数折叠/展开；点击函数调用关系跳转；“展开并打印”可用浏览器另存为 PDF。Markdown 版本便于编辑和批注。三张 SVG 可以独立打开、缩放或插入其他文档。

本手册基于 2026-09-11 的本地源码，Git bc6a87c。source_snapshot.json 记录分析文件的 SHA-256，用于核对后续变更。所有 C++ 翻译单元完成静态语法树解析；这不等于重新通过了学校测试器或在 Fedora 上实测。

复习资料位于项目的 `docs/review` 目录。网页使用相对路径引用样式、脚本、结构图和项目源码，因此复制完整项目后仍可直接打开。外部 tester/cgi_tester 未提供源码，因此不列内部函数。

阅读时注意：函数“没有显式调用者”、私有的“仅声明接口”、系统自动触发的构造/析构/信号回调是不同情况，笔记分别标注。
